# Source Dataset

## Dataset file

**File:** [Nexora_Retail_Raw_Dataset.xlsx](Nexora_Retail_Raw_Dataset.xlsx)

This workbook is the original raw dataset used for the Nexora Retail Nigeria Ltd. Power BI portfolio case study. It is the source input for the analysis covering **January 2025 to June 2026**, before the data preparation, cleaning, and transformations documented in the Power BI project.

## Source and acknowledgement

The dataset was provided by **Welup Digital** as part of **Cohort 14 of its Data Analytics course**. Credit and acknowledgement are given to Welup Digital for providing the dataset for the cohort assessment.

This repository uses the dataset for a portfolio case study demonstrating data preparation, data modelling, DAX measures, dashboard development, quality assurance, and business analysis. The analysis and report are the portfolio author's work; this does not imply that Welup Digital endorses the analysis or its conclusions.

## Important notes

- This is the raw source workbook, not the cleaned analytical output.
- Data limitations identified during QA are documented in the [Data Quality and Limitations note](../documentation/data-quality-and-limitations.md) and the [Comprehensive QA Report](../documentation/qa-report-2026-10-14.md).
- The reporting period is January 2025–June 2026. The absence of 2024 data limits full-year year-over-year comparisons.
- Findings should be interpreted as analytical and decision-support signals, not as audited financial statements or proof of causation.
